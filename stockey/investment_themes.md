## Screener Logic by Holding Period

### Long term screener bias
- prefer large cap, mid cap, and only cleaner small caps
- require balance-sheet quality
- require earnings visibility or order-book visibility
- allow staged entries even if not at perfect breakout point
- focus on structural tailwind + execution quality

### Medium term screener bias
- allow more cyclicals and rerating candidates
- require visible 1-4 quarter trigger
- prefer improving trend and relative strength
- prefer stocks close to breakout or in trend continuation
- valuation can be richer if earnings support exists

### Swing screener bias
- require liquidity filter first
- require strong price-volume action
- require proximity to breakout / fresh breakout / tight base
- prefer event-backed moves, not random momentum
- use strict invalidation and avoid averaging down

## Exit Trigger Types

### Thesis exit
- regime weakens
- theme loses relevance
- expected order/earnings trigger does not arrive

### Fundamental exit
- weak quarterly numbers
- margin collapse
- order-book slowdown
- balance-sheet deterioration

### Technical exit
- failed breakout
- loss of key moving averages
- weekly structure breakdown
- relative strength deterioration

### Time exit
- swing setup does not move within expected time
- medium-term rerating stalls after catalyst window
- thesis remains correct but capital is dead for too long
